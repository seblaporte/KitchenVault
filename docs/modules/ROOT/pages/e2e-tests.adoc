= Parcours utilisateurs (tests E2E)
:description: Vidéos générées depuis les tests Cypress, illustrant les principaux parcours utilisateurs

Cette page présente les principaux parcours utilisateurs de KitchenVault sous forme de vidéo, générées directement depuis les tests Cypress du frontend (`frontend/cypress/e2e/`). Chaque vidéo correspond à un fichier de spec et illustre l'ensemble des scénarios qu'il couvre — utilisez les contrôles du lecteur pour mettre en pause et avancer/reculer à votre rythme.

== Régénérer les vidéos

[source,bash]
----
cd frontend
npm start          # dans un terminal, laisser tourner (http://localhost:4200)
npm run e2e:video   # dans un second terminal
----

Chaque commande d'action Cypress (clic, saisie, navigation...) déclenche automatiquement un screenshot (voir `cypress/support/e2e.ts`), stocké par spec dans `cypress/screenshots/`. Chaque image porte un bandeau à deux niveaux — le scénario (`describe`/`it`) en cours, et une légende précise de l'action effectuée (ex. « Clic : Retour à la liste ») — ainsi qu'un point rouge sur l'élément ciblé par un clic. Ces images sont ensuite assemblées en vidéo mp4 via `sharp` (bandeau) puis `ffmpeg` (une image affichée ~0.9s) directement dans `docs/modules/ROOT/assets/images/e2e/`.
