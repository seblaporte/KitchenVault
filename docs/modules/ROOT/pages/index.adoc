= KitchenVault
:description: Documentation de l'application personnelle de gestion des recettes Cookidoo

KitchenVault est une application personnelle permettant de récupérer, stocker et consulter les recettes Cookidoo via une interface plus ergonomique que l'application officielle.

== Vue d'ensemble

L'application est composée de trois parties :

[cols="1,2,2"]
|===
|Composant |Rôle |Technologie

|`cookidoo-service`
|Wrapper autour de l'API Cookidoo non-officielle
|Python 3.12 · FastAPI · cookidoo-api

|`backend`
|API REST, persistance, synchronisation planifiée
|Java 25 · Spring Boot 3.4 · PostgreSQL 17

|`frontend`
|Interface utilisateur
|Angular 21 · TailwindCSS 4
|===

== Fonctionnalités

* Synchronisation manuelle et automatique (cron) des recettes et collections Cookidoo
* Stockage persistant en base PostgreSQL
* Interface d'administration : statut des syncs, statistiques, déclenchement manuel
* Plan de repas hebdomadaire (déjeuner/dîner), déplacement de recettes planifiées, synchronisation bidirectionnelle avec le calendrier Cookidoo
* Liste de courses : sélection de recettes, consolidation automatique des ingrédients, articles personnalisés
* Assistant IA culinaire : recherche sémantique de recettes, planification et liste de courses assistées par chat
* API REST contract-first (OpenAPI Generator)
